# 内置插件参考

`packages/plugins/src/` 下每个目录负责一个插件。`manifest.ts` 声明轻量元数据，`index.ts` 实现激活逻辑、文本缓冲区扩展或非文本视图工厂。`packages/plugins/src/index.ts` 注册清单和动态加载器，禁用的实现不会导入。`shared/` 包含共享实现工具，本身不是插件。

| 目录／标识        | 功能                                       |
| ----------------- | ------------------------------------------ |
| `markdown`        | Markdown 语言和括号匹配                    |
| `markdown-visual` | 源码／实时预览、任务、链接和状态栏         |
| `markdown-html`   | 实时预览中的常见 HTML 标签                 |
| `vim`             | Vim 输入及空格命令适配                     |
| `file-browser`    | 目录选择器和文件操作                       |
| `navigation`      | 命令／帮助、缓冲区和主题选择器             |
| `outline`         | 可搜索的 Markdown 标题和源码跳转           |
| `text-files`      | 文本文件、按需语言高亮和语言选择           |
| `media-viewer`    | 只读 PDF／图片查看、导航、缩放、搜索和大纲 |
| `history`         | 历史版本预览与恢复                         |
| `theme-minimal`   | 中性色板与高亮                             |
| `theme-folio`     | Folio 色板与高亮                           |

插件可以导入 `@portleaf/core` 公共 API、自身文件、声明的上游模块和共享工具，不导入桌面层实现或其他插件的私有实现。跨插件操作通过公共命令完成。注册、生命周期、配置和命令示例见[插件开发约定](plugin-contract.md)。修改源码后需要重新构建，当前不支持运行时安装外部插件。主题通过 `theme` 选择，不将主题标识加入 `plugins` 数组。

## Markdown 语言

标识：`markdown`；API：`1`；无依赖。

为 Markdown 缓冲区提供上游 CodeMirror Markdown 语言和括号匹配，其他文本文件按原文显示。重命名跨越 Markdown 与文本扩展名时会刷新缓冲区扩展。该插件没有命令或额外设置，只贡献缓冲区扩展，其生命周期由 CodeMirror 管理。

## Markdown 实时预览

标识：`markdown-visual`；API：`1`；依赖 `markdown`，宿主会自动激活依赖。

使用 remark/GFM 和 KaTeX MathML 渲染现有 Markdown 文档：

- `markdown.toggle`：`Space m v`，切换视图；`markdownMode` 控制新缓冲区的初始源码／实时模式。
- `markdown.link`：`Space m l`，跟随链接。
- `markdown.task`：`Space m t`，切换任务标记。

应用级激活负责命令处理、状态按钮和缓冲区订阅。按需启动的应用级工作线程解析实时 Markdown；源码编辑只在命令请求时解析。插件释放时终止工作线程。原生状态字段和装饰负责缓冲区显示并复用未变化的组件；KaTeX 仅在显示公式时加载。源码和撤销共用原始文档。

## Markdown HTML

标识：`markdown-html`；API：`1`；依赖 `markdown-visual`，默认启用。已有显式插件列表时需要加入 `markdown-html`。

实时预览中渲染 HTML 块和包含行内 HTML 的段落，点击内容可编辑源码；图片路径相对于当前文档，链接使用应用的链接处理。HTML 排版沿用应用的字号和行高，图片按容器宽度等比例缩放。为了避免文档执行代码，支持常见文本、图片、表格和 `picture` 标签，不执行脚本或事件属性，也不使用任意样式。行内 HTML 段落中的 Markdown 标记按原文显示。源码模式保持原文。

## Vim

标识：`vim`；API：`1`；无依赖。

将上游 Vim 引擎接入公共命令注册表，并提供可翻页的空格前缀提示。该插件只贡献文本缓冲区扩展；非文本查看器没有 CodeMirror 视图，使用自己的局部输入和空格适配器，因此媒体查看不依赖 Vim。

空格后的按键序列来自已启用命令的声明。原生 `:w`、`:q`、`:wq` 调用宿主刷新／退出服务，不增加自定义 Ctrl 快捷键。缓冲区视图插件负责提示、事件处理和引用计数式键位映射。由于上游没有取消定义动作或 Ex 命令的接口，按需安装的委托会留在进程中，但不保留应用资源。

## 文件浏览器

标识：`file-browser`；API：`1`；无必需依赖。存在 `history.open` 时可通过局部 `H` 打开历史。

提供类似 Yazi 的目录选择器、文本／元数据预览和文本文件操作。`text-files` 为同一选择器贡献 UTF-8 文本列表；未启用时仍可浏览 Markdown 和已启用查看器支持的格式。`media-viewer` 贡献 PDF／图片条目，只预览元数据。已禁用查看器的已知格式不会进入文本浏览。

启用文本浏览时保留显式扩展名，无扩展名默认补充 `.md`。列表、预览和搜索排除点号开头的名称及隐藏目录下的所有路径；数据层仍支持显式打开隐藏文档。创建、复制、重命名和历史仅适用于文本。

| 命令           | 按键                            |
| -------------- | ------------------------------- |
| `files.open`   | `Space f f`                     |
| `files.create` | `Space f n`                     |
| `files.rename` | `Space f r`                     |
| `files.copy`   | `Space f c`                     |
| `files.mkdir`  | 隐藏命令，由选择器内的 `m` 调用 |

局部导航和操作声明在 `manifest.ts`。大列表只渲染受限的行窗口；预览使用防抖与缓存。应用级激活负责选择器、作用域提示、文件事件订阅、刷新定时器和命令处理；释放时移除界面并使待完成读取失效。历史通过公共命令服务传入选中文件路径调用。

## 导航

标识：`navigation`；API：`1`；无依赖。

通过共享的作用域选择器提供命令／帮助、缓冲区和主题选择。缓冲区列表包含文本、PDF 和图片，并根据活动缓冲区类型恢复焦点。文件浏览、历史和媒体查看是独立插件。文本中的空格绑定使用 Vim 普通模式，媒体视图通过自己的适配器访问同一命令注册表。

- `commands.open`：`Space Space`；`keys.show`：`Space ?`。
- `buffers.open`、`buffers.next`、`buffers.previous`、`buffers.close`：分别为 `Space b b`、`Space b n`、`Space b p`、`Space b d`。
- `theme.select`：`Space u t`；`app.quit`：`Space q q`。

激活时注册处理函数。核心层负责选择器基础设施，并在插件释放时关闭其作用域。命令和主题从注册表读取，不使用硬编码列表。

## 历史

标识：`history`；API：`1`；无依赖。

通过 Patchwork 数据服务预览和恢复文本文档版本。PDF／图片不进入 CRDT 历史，对当前查看格式发出的历史请求会返回仅支持文本的提示。

`history.open` 使用 `Space f h`。可选命令目标允许文件选择器传入文件及恢复焦点的回调。激活时注册处理函数并持有作用域历史选择器；停用时由核心层关闭选择器，恢复操作通过共享数据服务执行。

## 文档大纲

标识：`outline`；API：`1`；无依赖。

`outline.open`（`Space m o`）在共享的可搜索选择器中显示当前 Markdown 文档标题。条目包含标题深度与源码行，初始选中当前章节；方向键或 `hjkl` 导航，`/` 搜索，`Enter` 跳转，`Esc` 返回编辑器。

解析器与 Markdown 实时预览共享 remark/GFM／前置元数据处理逻辑，支持 ATX、Setext、嵌套标题、行内格式和 Unicode，排除代码块与前置元数据。解析在按需启动的工作线程中执行。插件独立于 `markdown-visual`，可在源码和实时模式工作，不修改文本或撤销历史。

文档变化或活动缓冲区切换时，大纲关闭以避免使用过期位置；过期解析结果会被忽略。释放时终止解析器、移除订阅并关闭自己的选择器。纯文本文件不生成 Markdown 大纲。

## 文本文件

标识：`text-files`；API：`1`；无依赖。

通过 `fileBrowsing: { text: true }` 将文件选择器（`Space f f`）、递归文件名搜索和预览扩展至各种扩展名的 UTF-8 文本，包括 `.txt`、`.json`、`.nix`、`.ts`、`.py`、`.sh` 及 `Makefile`、`LICENSE` 等无扩展名文件。非 Markdown 候选文件使用最多 8 KiB 前缀检查，打开时校验整个文件；文本流程拒绝二进制和无效 UTF-8。已注册的 PDF／图片格式交给启用的提供者，提供者禁用时由宿主拒绝作为文本打开。

`text.open`（`Space f t`）提示输入已有的工作区相对路径，可包含隐藏路径。`text.create` 在命令列表中显示为 `New text file (exact name)`，按输入路径精确创建文件，包括无扩展名文件；父目录必须已经存在。选择器的 `n` 会保留显式扩展名，无扩展名仍默认补充 `.md`。

文本缓冲区共享 Vim 编辑、独立撤销、CRDT 自动持久化与文件导出、外部更新、历史、复制、重命名和恢复。UTF-8 BOM 与 LF/CRLF 得以保留；混合换行以只读模式打开。普通文本按原文显示，支持括号匹配，不参与 Markdown 解析或实时预览，也没有 `LIVE/SOURCE` 按钮。

语法高亮使用 CodeMirror 语言基础设施和上游 `@codemirror/language-data` 目录，按需加载语法，并复用上游加载去重与重试。Nix 语法来自 `@replit/codemirror-lang-nix`。现有主题色板为关键字、注释、字符串、数字、类型、函数、属性和标记属性着色，不改变排版。项目不包含语言服务器。

`text.language`（`Space u l`）和状态栏 `File language` 按钮打开可搜索的语言列表，包含自动识别（`Auto-detect`）、纯文本（`Plain text`）及支持的语言。选择只属于当前缓冲区，在主题重配置和文本文件重命名后保留，不进入撤销或持久化；关闭缓冲区后重置。Markdown 缓冲区仍使用独立 Markdown 插件。

自动识别依次检查上游文件名／扩展名、常见配置名（如 `.zshrc`、`.bashrc`、`.env`、`flake.lock`、`Cargo.lock` 和 Dockerfile 变体），以及未匹配文件中有限长度的脚本解释器声明。上游精确匹配失败后，还会忽略扩展名大小写重试。编辑无扩展名脚本的解释器声明或重命名文件会更新自动识别。未知文件使用纯文本；语言目录不会从任意自由文本推断语言，可手动指定。

解析和高亮使用 CodeMirror 原生状态与 Compartment。切换语言、关闭缓冲区或禁用插件后，迟到的加载结果会被忽略。加载失败时显示错误并保留可编辑的纯文本，重新选择语言可重试；打开或修改高亮不会重写文件。测试覆盖原生和旧式语法、字节保留、主题变化、重命名、缓冲区独立选择、撤销、失败重试及过期加载。

禁用插件会移除通用文本浏览和相关命令，保留 Markdown 和已启用查看器贡献的格式；已打开文本缓冲区仍可编辑并正常保存。文件系统边界、符号链接校验和选择器隐藏路径过滤仍然生效；显式打开隐藏路径可使用 `Space f t`。

## 媒体查看器

标识：`media-viewer`；API：`1`。不依赖 Vim、Markdown、`text-files` 或 `file-browser`。

通过公共 `fileViewer` / `createView` 约定提供只读 PDF 和图片缓冲区。支持 PDF、PNG、JPG/JPEG、GIF、WebP、AVIF、BMP、SVG 和 ICO，具体效果取决于 Chromium 解码能力及文件有效性。GIF 使用浏览器原生动画播放。

### 启用与打开

默认配置启用该插件。已有显式 `plugins` 数组时，保留所需插件并加入 `"media-viewer"`。`navigation` 提供命令列表和共享缓冲区命令，`file-browser` 提供文件选择器。

构建后可直接打开文件：

```sh
pnpm start /path/to/book.pdf
pnpm start /path/to/image.png
```

在应用中使用 `Space f v`（`media.open`），或启用文件浏览器后使用 `Space f f`。输入路径相对于打开的目录，可显式指定隐藏文件；浏览和搜索会隐藏点号开头的路径。预览只显示元数据，不渲染文档。提供者禁用时，其格式不会进入文本浏览。

查看器中的全局空格命令不依赖 Vim。`q` 关闭当前缓冲区；启用 `navigation` 时，`Space q q` 退出应用。空格是命令前缀，不用于翻页或暂停 GIF。

| 适配窗口                 | `a`                               | `s` 切换窗口／宽度适配   |
| 适配宽度                 | `s`、`w`                          | `w`                      |
| 原始大小                 | `=`                               | `a`、`=`                 |

两种查看器均支持 Ctrl 加滚轮缩放；PDF 支持鼠标中键拖动，左键拖动用于选择文本。PDF 翻页在首尾停止。图片目录导航循环切换并替换当前图片槽，释放上一个视图；按路径打开的文件可以占用独立缓冲区。缓冲区打开期间保留视图状态，不跨会话保存阅读位置。

命令列表还提供 `media.next`、`media.previous`、`media.fit`、`media.width`、`media.actual`、`media.zoom-in`、`media.zoom-out`、`media.rotate`、`media.reload`、`media.search`、`media.outline` 和 `media.goto`。

### 配置

选项位于 `pluginSettings.media-viewer`：

```json
{
  "pluginSettings": {
    "media-viewer": {
      "zoomStep": 1.2,
      "maxCanvasPixels": 16000000,
      "imageBackground": "checkerboard"
    }
  }
}
```

| 选项              | 默认值           | 可接受值                       |
| ----------------- | ---------------- | ------------------------------ |
| `zoomStep`        | `1.2`            | 1.05 至 2 的有限数值           |
| `maxCanvasPixels` | `16000000`       | 1000000 至 32000000 的有限数值 |
| `imageBackground` | `"checkerboard"` | `"checkerboard"` 或 `"theme"`  |

无效值回退到默认值；后续缩放和重绘读取当前配置。逻辑缩放范围为 2% 至 1600%，PDF 画布分辨率另受像素预算和 16384 像素最大边长限制。预算针对单页画布，不是进程总内存限制。

### 加载与清理

PDF.js 及其专用工作线程仅在打开 PDF 时加载；图片使用原生解码，不加载 PDF 后端。二进制文件不创建 CodeMirror 实例，也不进入 CRDT 历史或文本导出。PDF 通过经过校验的本地资源 URL 和上游公共分段传输接口读取。字体、CMap、图片解码 WASM 和许可证会复制到 `dist/pdfjs`，供离线使用；即使禁用插件，内置资源仍包含在构建中。

每个视图负责自身 DOM、请求、解码图片引用、PDF 工作线程、尺寸观察器和资源订阅。隐藏 PDF 视图时释放页面画布、取消渲染，但保留已加载文档和工作线程；关闭缓冲区或禁用提供者时销毁资源。加载和渲染结果按版本校验，释放时平衡资源监听引用。活动文件变化会防抖后重新加载；隐藏视图会使旧资源失效，等待下次激活。重新加载会清空 PDF 搜索结果。

搜索按需提取 PDF 已有文本，最多保存 200 条匹配并高亮所选结果；大纲最多保存 1000 项。取消、切换缓冲区、重新加载或释放视图都会使旧搜索／大纲请求失效。

### 功能边界与验证

当前一次显示一页 PDF，不支持连续／双页布局、OCR、密码输入、PDF 链接／表单／批注／编辑、图片编辑、幻灯片或 GIF 帧控制。媒体文件不使用文本历史及当前文本文件创建、复制、重命名操作；这些操作需要外部工具。

集成测试覆盖真实 PDF 工作线程与非空画布、跨多个分块的范围响应、页面尺寸、文本搜索与高亮、大纲、图片导航／缩放／旋转、规范路径复用、错误恢复、不启用 Vim／Markdown 的启动、提供者禁用及加载期间关闭。截图附在测试结果中，位于 `test-results/electron/`。

资源策略见[性能说明](performance.md)。PDF.js 使用 Apache-2.0 许可证，附属资源目录保留各自上游许可证声明。

## Minimal 主题

标识：`theme-minimal`；API：`1`；无依赖。

提供 `minimal` 色板和原生语法高亮。通过 `"theme": "minimal"` 选择，不要将主题标识加入 `plugins`。核心层独立于缓冲区应用色板，CodeMirror 管理缓冲区高亮；该主题不持有 DOM 订阅，也不改变排版。

## Folio 主题

标识：`theme-folio`；API：`1`；无依赖。

提供 `folio` 色板和原生语法高亮，可使用配置中提供的 Folio 外观数据。通过 `"theme": "folio"` 选择，不要将主题标识加入 `plugins`；没有外观数据时使用共享中性默认值。核心层独立于缓冲区应用色板，CodeMirror 管理高亮，宿主负责字体、字号和行高网格。
